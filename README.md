# GS4XP – Ground Services for X-Plane 12

Ground vehicles, animated passengers and ramp crew, and the full turnaround around your aircraft, with its own window in X-Plane 12.

> **Beta:** GS4XP checks for updates when X-Plane starts and installs them, most of the time without a restart. Please report anything that looks wrong.

## Download

Get the installer for your computer from **[Releases](https://github.com/GS4XP/NumidiaGSE/releases/latest)**:

| | |
|---|---|
| **Windows** | `GS4XP-<version>-Setup-Windows.exe`: run it. Windows may say "Windows protected your PC" (the installer isn't code-signed yet): click *More info › Run anyway*. |
| **Mac** (Apple Silicon and Intel) | `GS4XP-<version>-Setup-Mac.pkg`: open it. If macOS says it can't check it for malicious software, right-click the file › *Open*, or allow it in *System Settings › Privacy & Security*. |
| **Linux** | `GS4XP-<version>-Setup-Linux.run`: in a terminal, `sh GS4XP-<version>-Setup-Linux.run` |

Each installer finds X-Plane 12 by itself, installs GS4XP into `Resources/plugins/GS4XP`, removes an earlier version (Numidia Ground Services) and keeps your own liveries.

## Using it

Open the window with **Plugins › GS4XP**, or bind a key to `gs4xp/toggle_window`.

## Updates

When a new version is out, a small window appears at the top right of X-Plane: click **Update now**, then restart X-Plane. Updates are digitally signed and checked before anything is installed.
